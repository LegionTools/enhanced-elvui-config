# Enhanced ElvUI Config

A fork of ElvUI's companion options addon (by Elv). The addon's own name and folder are left untouched per ElvUI's license; only the repository name differs.

## Status

This existed to add a "Height" slider for [enhanced-elvui](https://github.com/LegionTools/enhanced-elvui)'s independent minimap width/height feature. That feature was fully reverted (the game client's native minimap widget doesn't support a non-square size reliably), so the code here is currently unmodified stock ElvUI_Config.

## Installation

Replace your `ElvUI_Config` addon folder with this one (keep the folder named `ElvUI_Config`), `/reload`.

## Credits

All original code and design: Elv and the ElvUI contributors.

# Enhanced ElvUI Config (русский)

Форк аддона настроек ElvUI (автор Elv). Название и папка аддона не изменены — требование лицензии ElvUI; отличается только имя репозитория.

## Статус

Этот репозиторий существовал для слайдера "Height" к фиче независимой ширины/высоты миникарты в [enhanced-elvui](https://github.com/LegionTools/enhanced-elvui). Та фича полностью откачена (нативный виджет миникарты клиента игры не поддерживает непрямоугольный размер надёжно), поэтому код здесь сейчас — немодифицированный стоковый ElvUI_Config.

## Установка

Замените папку аддона `ElvUI_Config` на эту (папку не переименовывать, оставить `ElvUI_Config`), сделайте `/reload`.

## Благодарности

Весь оригинальный код и дизайн: Elv и контрибьюторы ElvUI.
